## 0. Organizatoric
| Despre | Ce presupune
| - | - |
| Nota | proiect (7p) + (întrebare OR interogare (3p))
| | [Întrebarea](./exemple_intrebari/)/[interogarea](./exemple_interogari/) este aleatorie.
| | Întrebare curs = 1p ideea generală + 1p exemplu + 1p dacă nu a fost nevoie de indicii / intervenție
| | Întrebările din curs sunt de la primul curs până la laboratorul unde se anunță următorul laborator. (ex: cursurile 1-5 pentru L3 anunțat în săptămâna 5)
| | Interogare = 1p ideea generală + (2p (implementare perfectă) OR 1p (implementare ok, cu greșeli și nu se reușește rezolvarea după mai multe încercări))
| [Examen practic](./exemple_practic/) | 1 oră examen practic - 1 oră verificat |
| Penalizare | 0.5p / săptămână |
| Restanțe | se acceptă laboratoarele, dar notarea se face doar cu 65% din nota totală |
